Correction des questions ouvertes par IA

Avec une clé API Anthropic, Claude analyse le sens des réponses ouvertes (reformulations, synonymes, erreurs, hors-sujet) et propose une note détaillée, que l'enseignant valide. Sans clé, une analyse locale fondée sur le vocabulaire est utilisée, et ses notes sont à vérifier. La clé se crée sur console.anthropic.com ; l'utilisation de l'API est payante.
